# iOS — Pulse

Swift + SwiftUI. Project file is generated by `xcodegen` from `project.yml` — do not commit `.xcodeproj`.

## First-time setup

```sh
cd ios
brew install xcodegen     # if not already
xcodegen generate         # creates Pulse.xcodeproj
open Pulse.xcodeproj
```

## Config

Edit `Pulse/Config.xcconfig` to point at your Supabase project. Both values
ship in the app bundle (the Supabase anon key is publishable; never put secret keys here).

## Build

- In Xcode: select an iPhone simulator and ⌘R.
- From CLI: `xcodebuild -project Pulse.xcodeproj -scheme Pulse -destination 'platform=iOS Simulator,name=iPhone 15' build`.

## KMP shared module (future)

The iOS app currently uses hand-mirrored Swift types in `Models.swift` matching
the KMP shared module at `../shared/`. Migration to direct `import SharedKit`:

1. From repo root: `./gradlew :shared:assembleSharedKitXCFramework` (after `gradle wrapper` has run once).
2. Uncomment the `dependencies` + `preBuildScripts` block in `project.yml`.
3. Re-run `xcodegen generate`.
4. Delete `Models.swift` and `import SharedKit` from `ApiClient.swift`.

Source-of-truth for the shared types stays in `shared/src/commonMain/kotlin/com/austinconnor/pulse/shared/Types.kt`. Until the migration, any change there must be mirrored to `Models.swift`.
