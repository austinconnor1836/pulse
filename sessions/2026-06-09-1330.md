- **iOS app structure**: xcodegen-generated Xcode project (no `.xcodeproj` in git), Apple Team ID `L6AS5GG2MB` wired in, Bundle ID `com.austinconnor.nycdayplanner`.
- **IA pivot to 2-tab bottom bar**: dropped Home → drill-down. New tabs: **Things to Do** (search to narrow + ranked list with score breakdown) and **Planner** (Today / Tomorrow / This Week segmented; per-day cards with detail drill-in).
- **Heuristic is 5 signals, not 4.** Added Real-time event relevance as the 5th signal with breaking-news bump. Recency got a venue-activity sub-signal (+2 if venue posted in last 48h).
- **Business profile** as a semantic layer on top of business universe — scrape each business's own website, LLM-extract specific business type, products, services, vibe descriptors, per-purpose fit scores. Coarse Yelp/Google categories become irrelevant.
- **User-decision feedback loop** is in the architecture as a moat-compounder. Deterministic 5-signal heuristic stays explainable; three channels tune it: per-user personalization (±0.3 bounded), per-spot cross-user reinforcement, aggregate signal metrics for quarterly human-curated weight tuning. No black-box ML in the critical path.
- **TestFlight ship path documented** at `ios/SHIP_TO_TESTFLIGHT.md`. Three manual prereqs (PLA accept, iOS 26.5 platform download or device-direct workaround, App Store Connect record).
- **iPhone-direct dev flow** documented at `ios/RUN_ON_DEVICE.md` — skips simulator runtime download entirely; ~30s iterations via ⌘R.

## Trade-offs flagged

- **Native + KMP vs Expo**: chose native for App Store ceiling and platform feature access (HealthKit, widgets, etc.). Cost: 2x UI codebases. Justified by investor-pitch trajectory.
- **iPhone-direct dev vs simulator**: chose to document iPhone-direct as primary dev flow. Skips multi-hour simulator runtime download. Cost: can't test across device sizes locally; sim is the right tool for that. Acceptable for solo dev iteration.
- **Hand-mirrored Swift types vs KMP XCFramework Day 1**: chose hand-mirror for first scaffold. Cost: type drift risk between `Types.kt` and `Models.swift`. Mitigation: rule that any Kotlin type change must be mirrored, plus migration path documented.
- **Lean MVP (~$50/mo) before backend wire-up**: chose to invest scaffolding time in architecture coverage (migrations, types, docs) before implementing any Edge Function. Cost: nothing runs end-to-end yet. Justified for investor demo: the architecture is the moat narrative.
- **Vibes-based scoring in earlier "find spots" answer**: I made up scores instead of grounding them in the heuristic. User caught it. Re-ran in deep mode (50 parallel agents, 6 min compute) and produced grounded scores. **Rule for future sessions: when invoking the heuristic, actually run the heuristic — don't dress up vibes.**
