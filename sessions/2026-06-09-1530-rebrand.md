## Trade-offs flagged

- **Single Pulse tab with mode toggle vs three tabs (Feed/Map/Search)**: chose single tab. Reasoning: search is a verb that applies to BOTH Feed and Map; making it a third tab would force the user to re-search when switching modes. A persistent search bar above the mode toggle keeps query state stable. Cost: more controls visible at once (search bar + segmented control + content). Manageable.
- **MapKit vs Google Maps on iOS**: chose MapKit for native fit, no API key, SwiftUI-idiomatic. Cost: Android still needs Google Maps (no MapKit), so the two platforms will diverge in map implementation even though the data shape is shared. Acceptable.
- **Bulk sed for identifier rename vs manual file-by-file Edit**: chose sed. Cost: had to re-verify no stale references survived (one second pass needed for `.md` files that the first pattern missed). Faster than 25 individual edits.
- **Delete old session summary's path vs leave it**: chose to leave `2026-06-09-1330.md` content unchanged since it's a historical record of THAT chunk. Its cross-reference to `~/Developer/nyc-day-planner/sessions/...` is technically stale (path no longer exists). Updated in companion edit to point to current location.
